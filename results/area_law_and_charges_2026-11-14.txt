B) Charges from consistency (anomaly cancellation; Geng & Marshak 1989; Minahan, Ramond & Warner 1990; Bar & Wiese 2001).
   One generation with N colours: quark doublet Q(N,2), u(N), d(N), lepton doublet L(2), e(1); fix the scale with Y_L = -1/2.
   N = 1: up-quark charge 1, down-quark charge 0, electron -1, neutrino 0
   N = 2: up-quark charge 3/4, down-quark charge -1/4, electron -1, neutrino 0
   N = 3: up-quark charge 2/3, down-quark charge -1/3, electron -1, neutrino 0
   N = 4: up-quark charge 5/8, down-quark charge -3/8, electron -1, neutrino 0
   N = 5: up-quark charge 3/5, down-quark charge -2/5, electron -1, neutrino 0
   Result: for ANY number of colours N the anomalies cancel, with up = 1/2 + 1/(2N) and down = -1/2 + 1/(2N).
   So the charges are forced ONCE N is known, and N = 3 gives exactly +2/3 and -1/3. N itself is not forced by
   anomalies; it is measured (e.g. the neutral pion decay rate and the e+e- -> hadrons ratio both need N = 3).
