1. The fold strength in matrix terms
========================================================================================================
  Level repulsion: k p0 = g^2 / M_D  ->  k = (g / sqrt(p0 M_D))^2. The ladder scale p0 ~ m_b/3 = 958 MeV at the top's energy.
  sqrt(p0 M_D) is TRPG's balance point between the ladder and the heavy part, so k is the squared link measured against that balance.
  The best folds (earlier tests, down only) have |k| about 0.11-0.12, so g = 0.34 x balance (sign = the heavy part's mass sign).

========================================================================================================
2. Which ladder: down only (E6 27 has a heavy D and no heavy U)
========================================================================================================
  27 = 16 + 10 + 1 under SO(10); the 10 holds one down-type colour triplet pair (D, Dbar) and a Higgs-like doublet pair; no up-type partner.
  So level repulsion from the far-side coloured part can only reach the down ladder: V1 (down only) is the variant the matrix allows.

5. The far-side scale and the first-row leak
========================================================================================================
  far-side pairs: M_D = 2.60e+07 GeV -> mixing^2 = k p0 / M_D = 4.3e-09; first-row leak = mixing^2/6 = 7.1e-10
  an earlier test exact far-side mass: M_D = 2.13e+08 GeV -> mixing^2 = k p0 / M_D = 5.2e-10; first-row leak = mixing^2/6 = 8.7e-11
  Measured shortfall 1.6e-3. If the fold's heavy part sits at the far-side scale, it leaks only about 1e-10 to 1e-9: the first row must close.
  Prediction: the 2.2 sigma 'Cabibbo angle anomaly' is not a leak into TRPG's heavy D; it must shrink as the data improve.
