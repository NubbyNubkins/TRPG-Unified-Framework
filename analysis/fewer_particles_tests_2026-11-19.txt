2. ANOMALY CANCELLATION: is one generation reducible?
  full generation (15 states)            Y^3=0, grav-Y=0, SU2^2 Y=0, SU3^2 Y=0, SU2 doublets=4  -> CONSISTENT
  quarks only                            Y^3=-3/4, grav-Y=0, SU2^2 Y=1/2, SU3^2 Y=0, SU2 doublets=3  -> BROKEN
  leptons only                           Y^3=3/4, grav-Y=0, SU2^2 Y=-1/2, SU3^2 Y=0, SU2 doublets=1  -> BROKEN
  drop right-handed electron             Y^3=-1, grav-Y=-1, SU2^2 Y=0, SU3^2 Y=0, SU2 doublets=4  -> BROKEN
  drop down-type quark (u only)          Y^3=-1/9, grav-Y=-1, SU2^2 Y=0, SU3^2 Y=-1/3, SU2 doublets=4  -> BROKEN
  -> A generation is ONE unit: quarks alone or leptons alone are inconsistent. Supports 'one object', blocks dropping parts.

3. FORCE STRENGTHS: does REMOVING particles help them meet?
  1/alpha at MZ: 59.02, 29.58, 8.47.  Meeting needs B = (b2-b3)/(b1-b2) = 0.717
  Standard Model content                               B = 0.528   (reference)
  remove the Higgs doublet                             B = 0.500   further than SM
  gluons as quark links (no gluon self-loop)           B = -0.986   further than SM
  remove a whole generation                            B = 0.528   same as SM
  quarks without colour (1 copy each) [b3: no quarks feel colour] B = 0.748   closer than SM
  ADD a 2nd Higgs doublet                              B = 0.556   closer than SM
  MSSM (doubles the particles)                         B = 0.714   closer than SM
  -> Removals that data allow make it worse or leave it unchanged. The one removal that helps (colourless quarks)
     is excluded by the R ratio and pi0 width above. ADDING states (2HDM, MSSM, TRPG's far-side MMG) is what moves it closer.
  Strong-force running check (one loop, 5 flavours throughout, so only rough): alpha_s(m_tau)=0.315 measured, alpha_s(MZ)=0.118.
    with gluon self-loops (b0=11-2*5/3=7.67): 0.315 at 1.777 GeV -> 0.125 at MZ
    gluons as passive links (b0=-2*5/3):        0.315 at 1.777 GeV -> 0.921 at MZ  (grows; FAILS)
